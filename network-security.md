# Network Security

## Overview

This section documents the study of network security completed through the Cisco Networking Academy curriculum during the INSA Summer Camp.

Before investigating security vulnerabilities, understanding how the systems being secured communicate is essential. Understanding how network devices connect, how packets move through networks, how addressing functions, and how services communicate provided the foundation needed to analyze security problems at both the network and application levels.

## Foundational Networking and Security Topics

The CCNA: Introduction to Networks curriculum provided foundational knowledge across network architectures, protocols, addressing, device configuration, and defensive controls:

- Network components and architectures: Understanding the roles of hosts, switches, routers, gateways, and transmission media in local and wide area network architectures.
- LANs and network communication: Principles of data transmission across local area networks.
- OSI and TCP/IP models: Layered protocol architectures and the mechanics of data encapsulation and decapsulation across layers.
- Network protocols: How standardized protocols govern communication across disparate network devices and operating systems.
- Ethernet and switching: Frame structures, switch MAC address tables, and Layer 2 frame forwarding decisions.
- MAC addresses: Layer 2 physical addressing and broadcast domain boundaries.
- IPv4 and IPv6 addressing: Layer 3 logical addressing, address classes, and IPv6 global unicast and link-local addressing structures.
- Subnetting: Calculating subnet masks, network prefixes, host ranges, and subnet boundaries to segment networks effectively.
- Routing concepts: How routers determine packet forwarding paths across network segments.
- ARP and IPv6 Neighbor Discovery: Resolving Layer 3 logical IP addresses to Layer 2 physical MAC addresses.
- ICMP: Operational messaging, error reporting, and network reachability testing using echo request and reply mechanisms.
- TCP and UDP: Understanding transport layer protocols, comparing connection-oriented, reliable communication in TCP (three-way handshakes, sequence numbers, acknowledgments) with connectionless communication in UDP.
- Application-layer protocols: Port associations, functions, and behaviors of core protocols, including HTTP, DNS, DHCP, and SSH.
- Basic Cisco IOS configuration: Command modes, managing configuration files, and setting interface operational parameters.
- Router and switch configuration: Initial configuration of hostnames, IP addresses, default gateways, and management access.
- Network troubleshooting: Structured methodologies for isolating communication failures across protocol layers.
- Network security fundamentals: Concepts of data confidentiality, integrity, and availability (CIA triad) within network architectures.
- Network threats, vulnerabilities, attacks, and mitigation: Categories of security risks including unauthorized access, credential theft, denial of service attacks, malware propagation, and internal threat vectors.
- Basic device security: Switch and end-device hardening, securing remote management interfaces by replacing Telnet with SSH, administrative password policies, and switch port security.
- Building and securing a small network: Designing, configuring, and verifying connectivity and basic security controls across an integrated multi-device topology.
